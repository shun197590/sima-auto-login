# 產業園區安全防護系統 - 行動快速登入 PWA

本專案為針對「產業園區安全防護系統」設計之行動端輔助登入 PWA，可直接免費託管於 **GitHub Pages**。

---

## 快速部署至 GitHub Pages 步驟 (約 2 分鐘)

1. **建立儲存庫**：
   - 登入 GitHub，點擊右上角 **New repository**。
   - 命名為例如 `sima-quick-login`。
   - 選擇 **Public**（公開），勾選 **Add a README file**（或直接建立）。

2. **上傳程式檔案**：
   - 點擊專案頁面的 **Add file -> Upload files**。
   - 將本壓縮包解壓縮後的所有檔案拖曳進去：
     - `index.html`
     - `manifest.json`
     - `sw.js`
     - `icon-192.png`
     - `icon-512.png`
   - 點擊下方綠色按鈕 **Commit changes**。

3. **啟用 GitHub Pages**：
   - 在該儲存庫上方點選 **Settings** $\rightarrow$ 左側選單點選 **Pages**。
   - 在 **Build and deployment** 下的 **Branch** 選擇 `main`，資料夾保持 `/ (root)`。
   - 點擊 **Save**。
   - 等待約 1 分鐘後重新整理頁面，頂部會出現您的專屬 HTTPS 網址：
     `https://<你的帳號>.github.io/sima-quick-login/`

## 手機端安裝至主畫面

### iOS (Safari)
1. 用 Safari 開啟該 GitHub Pages 網址。
2. 點擊瀏覽器底部的 **分享圖示**（向上箭頭）。
3. 滑動選單點選 **「加入主畫面」**。

### Android (Chrome)
1. 用 Chrome 開啟網址。
2. 點擊右上角「三個點」選單。
3. 點選 **「安裝應用程式」** 或 **「新增至主螢幕」**。
